# عارض ملف GitHub — تطبيق PWA

تطبيق ويب تقدّمي (PWA) لعرض ملفات مستخدمي GitHub ومستودعاتهم ولغاتهم البرمجية،
مدمج مع GitHub REST API، ويمكن **تثبيته على الهاتف** كأي تطبيق native.

## كيف تشغّله على جهازك (محليًا)

```bash
npm install
npm run build      # ينتج مجلد dist/ جاهز للنشر
npm run dev        # للتطوير على http://localhost:5173
```

## كيف تنشره وتثبّته على هاتفك (GitHub Pages)

التثبيت على الهاتف يتطلب فتح التطبيق عبر رابط **HTTPS**. أسهل طريقة مع حساب GitHub:

1. أنشئ مستودعًا جديدًا في حسابك اسمه `github-viewer` (أو أي اسم).
2. بعد `npm run build`، ارفع محتويات مجلد `dist/` بالكامل إلى هذا المستودع
   (الملفات: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-512.png`).
3. في إعدادات المستودع ← **Pages** ← اختر الفرع `main` (أو `gh-pages`) ← `/root`.
4. بعد دقائق، افتح الرابط:
   `https://<اسم-المستخدم>.github.io/github-viewer/`
   من هاتفك.
5. **على أندرويد (Chrome):** اضغط القائمة (⋮) ← «إضافة إلى الشاشة الرئيسية».
   ستظهر أيضًا رسالة داخل التطبيق وزر «تثبيت التطبيق».
6. **على iPhone (Safari):** اضغط مشاركة ← «أضف إلى الشاشة الرئيسية».

> ملاحظة: إن استضفت التطبيق على مسار فرعي (مثل `/github-viewer/`)،
> عدّل `start_url` و`scope` في `manifest.webmanifest` إلى `/github-viewer/`
> وأضف `base: "/github-viewer/"` عند الإعداد (يُفضّل استضافته على
> موقع المستخدم `username.github.io` حيث الجذر هو `/`).

## محتويات مجلد `dist/`

- `index.html` — التطبيق كامل (single-file).
- `sw.js` — أداة العمل لتشغيل التطبيق دون اتصال.
- `manifest.webmanifest` — إعدادات التطبيق التقدّمي.
- `icon-512.png` — أيقونة التطبيق.

## الميزات

- بحث عن أي مستخدم على GitHub وعرض ملفه ومستودعاته.
- إحصائيات (المستودعات، النجوم، المتابعون).
- توزيع اللغات البرمجية بألوانها الرسمية.
- العمل دون اتصال (Offline) عبر Service Worker.
- تثبيت على الشاشة الرئيسية (Android & iOS).
